SF Marathon Garmin Workout Steps

Every workout, step by step, to build by hand in Garmin Connect. Use the search box (try "hill", "tempo", "M09" or a date), open a workout and press Copy to paste it into notes.

Build one in Garmin Connect (web or app)
  1. Training & Planning > Workouts > Create a Workout > Running.
  2. Add each step in order. Choose the step type (Warm Up, Run, Recover, Cool Down).
  3. Set the duration type (Distance, Time or Lap Button Press) and the target (Pace, Heart Rate or Open).
  4. For repeats, use Add Repeat and set the number of times, then put the steps listed in the Repeats column inside it.
  5. Name it and save. Create one of each type first, then copy and edit for later weeks.
Targets: easy = custom HR 131–157 bpm · hill reps and strides = Open target (effort) · tempo and marathon-pace steps = pace range · set Garmin to miles. "Lap button (about X mi)" = Lap Button Press.
